# OpenTick Scoop Bucket

A Scoop bucket for [OpenTick](https://github.com/JebbyCodes/OpenTick), an open-source cross-platform task manager.

## Installation

Install [Scoop](https://scoop.sh/) first, then run:

```powershell
scoop bucket add opentick https://github.com/JebbyCodes/OpenTick-Scoop
scoop install opentick
```

## Updating

```powershell
scoop update
scoop update opentick
```
